# 🌆 TerminalCity (NeonKent)

> Siberpunk temalı, ses ve görsel öğelerle zenginleştirilmiş interaktif terminal/simülasyon projesi.

---

## 📂 Dosya Yapısı

Projenizdeki ana bileşenler ve varlıklar (assets):

* **`neonkent.py`**: Projenin ana Python betiği / mantığı.
* **`pedestrian.json` / `pedestrian.webp`**: Yaya (pedestrian) animasyonları, model verileri veya görsel varlıkları.
* **`rain.mp3`**: Atmosferik yağmur ses efekti.
* **`sportscar.json` / `sportscar.png`**: Spor araba varlıkları ve model/görsel verileri.

---
